LRCLIB Publisher

Publikasikan plain lyrics dan timestamped LRC ke database LRCLIB. Tidak membutuhkan akun atau API key.

01 — Informasi lagu

Masukkan durasi audio dalam detik, bukan milidetik.

02 — Lirik

Pilih file .lrc untuk mengisi synced lyrics dan plain lyrics otomatis.

Format timestamp standar: [mm:ss.xx] atau [mm:ss.xxx]. Minimal isi salah satu jenis lirik.

03 — Publikasi

Siap. Lengkapi metadata dan lirik sebelum melakukan publikasi.

Saat publikasi, halaman akan meminta challenge baru, mencari nonce melalui SHA-256 Proof of Work, lalu mengirim token satu kali ke LRCLIB. Jangan tutup halaman selama proses berlangsung.

Client: Yoruuta LRCLIB Publisher prototype · API: https://lrclib.net/api
